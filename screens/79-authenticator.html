What is this code for?
A time-based one-time passcode (TOTP), like Google Authenticator, that proves this device belongs to your DigiLocker account.
Why does it change every 60 seconds?
Each code is valid for one time window only, so a leaked code can't be reused later.
Lost your device?
Sign in with MPIN/OTP on a new device and this code will regenerate using your account's secret key.
